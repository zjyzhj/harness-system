# G4-SPEC — 多 Bot 协作与编排

> Goal：G4 · 状态：⏳ 待实现 · 上游：[AUDIT.md](../AUDIT.md)（缺口 #5）· 下游：[G4-design](./G4-design.md)
> 目标：从「两 bot 互发文本」升级为「群组广播 + 富内容互发 + 主控编排器」，一条指令调动多 bot 完成流水线。

## 1. 问题陈述

MessageBus 只能两 bot 互发文本；无群组、无广播、无编排；HTTP Transport 预留但无服务端，无法跨进程。

## 2. 用户故事

- 作为用户，我建一个**群组**（如「产品组」），一句话 @组 让所有组员 bot 各自回应。
- 作为用户，bot 之间能传**富内容**（图片/文件/工具结果），不是只有文本。
- 作为用户，我给主控一句话：「让 A 调研、B 总结、C 写成报告」→ 主控自动编排流水线，最终产出交回我。
- 作为用户，多个 harness 实例（两台机器）可通过**网关**互联，远程 bot 参与协作。

## 3. 功能需求

| # | 需求 | 验收 |
|---|------|------|
| F1 | 群组（create/join/leave/list） | 建组后 @组 广播生效 |
| F2 | 富内容互发（图片/文件/tool 结果块） | A 传图给 B，B 能收到并显示 |
| F3 | 编排器（顺序流水线 / 并行 fan-out / 汇总） | 一条指令产出最终报告 |
| F4 | 编排可视化（进度/依赖/结果） | 面板看到流水线阶段状态 |
| F5 | HTTP 网关（服务端实现 + 客户端） | 跨进程 bot 通信成功 |
| F6 | 权限：编排只能由主控/授权 bot 发起 | 非授权 bot 不能指挥 |
| F7 | 迁移：群组/编排结果随导出 | 迁移往返 |

## 4. 非功能

- 编排任务可中断/超时/重试；每个阶段结果可审计。
- 网关消息加密（token）；失败自动标记。

## 5. 边界

- 不做通用工作流 DAG 编辑器（超范围）；支持链式/扇出两种。
- 不做云端编排服务；网关为本机/局域网自建。

## 6. 验收清单

- [ ] F1–F7 全过；编排「A 调研→B 总结→C 写作」演示通过
- [ ] 群组广播 + 富内容互发 + 网关互通均有测试
