# G2-SPEC — 记忆升级（语义检索 + 权威总结 + 共享知识）

> Goal：G2 · 状态：✅ 已完成 · 日期：2026-10-27 · 上游：[AUDIT.md](../AUDIT.md)（缺口 #3）· 下游：[G2-design](./G2-design.md)
> 目标：让 bot 记得住、记得准：语义级记忆检索、MEMORY.md 权威总结常驻、跨 bot 共享知识空间。

## 1. 问题陈述

当前记忆=关键词检索（`KeywordRetriever`）+ 事实/摘要简单切片注入。「我喜欢吃辣」在 100 条记忆里，问「我的口味偏好？」召回不到；各 bot 记忆互相隔离，无法沉淀团队知识。

## 2. 用户故事

- 作为用户，我**换一种说法**问 bot，它仍能想起此前记下的相关事实（语义而非字面）。
- 作为用户，每个 bot 有一份**权威总结**（像人的长期记忆提纲），常驻上下文但极小。
- 作为用户，我可以创建一个**共享知识库**，多个 bot 一起用（如团队约定、产品文档要点）。

## 3. 功能需求

| # | 需求 | 验收 |
|---|------|------|
| F1 | 语义检索（向量/嵌入降级关键词） | 模糊问法召回正确事实 |
| F2 | MEMORY.md 权威总结：定期/按触发条件用 LLM 重写 | 总结常驻 system；随新记忆自动更新 |
| F3 | 共享知识空间（namespace：bot 私有 / group 共享 / 全局） | 指定 bot 可读共享记忆 |
| F4 | 记忆浏览/编辑 UI | 面板可看/改/删/合并记忆 |
| F5 | 记忆来源标注（会话/定时/手动/工具）+ 时间线 | 可追溯 |
| F6 | 容量上限 + 合并/清理策略 | 超限自动合并同类、淘汰低价值 |
| F7 | 兼容现有记忆数据 | 启动迁移不丢 |

## 4. 非功能

- 零/极轻依赖：优先 **本地哈希向量 + 余弦**（不强制外部嵌入 API）；有嵌入 provider 时自动用真向量。
- 检索延迟 < 50ms（万级条目）。
- 记忆文件仍 human-readable（md/json 可手工改）。

## 5. 边界

- 不做记忆图数据库/知识图谱（超范围）。
- 嵌入 API 为可选增强，缺失时走关键词+哈希向量混合兜底。

## 6. 验收清单
