# G3-SPEC — 桌面宠物深度化

> Goal：G3 · 状态：⏳ 待实现 · 上游：[AUDIT.md](../AUDIT.md)（缺口 #4）· 下游：[G3-design](./G3-design.md)
> 目标：宠物从「表情徽章 + 临时气泡」升级为「多形态动画 + 气泡会话入口 + 任务结果展示 + 闹钟」的桌面伴侣。

## 1. 问题陈述

宠物现在只有 breathe/bounce/pop + 情绪徽章；气泡是临时 DOM 无法回看；定时任务结果只走系统通知不进宠物；形象是静态头像，与动画未打通。

## 2. 用户故事

- 作为用户，宠物有**多种形态/动画**（走、跳、眨眼、睡觉、心情变化），形象生成后可选择动作皮肤。
- 作为用户，点宠物气泡里的消息可以**打开对应会话**（回看历史、继续对话）。
- 作为用户，**定时任务完成/失败**时宠物气泡直接展示结果，不用切窗口。
- 作为用户，宠物可以当**闹钟/提醒**（"15 分钟后提醒我喝水"→ 宠物准点弹气泡+通知）。

## 3. 功能需求

| # | 需求 | 验收 |
|---|------|------|
| F1 | 形态系统：多动作帧（idle/walk/jump/sleep/celebrate）+ 状态→动作映射 | 切状态触发对应动画 |
| F2 | 形象→皮肤：生成形象时可选风格（像素/圆润/写实），宠物动画套用 | 换形象后动画风格同步 |
| F3 | 气泡内富文本（markdown/代码/图片/工具卡片） | 宠物显示结果与面板一致 |
| F4 | 气泡历史入口（“查看完整会话”） | 点击从面板打开该会话 |
| F5 | 任务结果进宠物（定时任务 done/error 富展示 + 置顶提醒） | 任务完成宠物气泡立即展示 |
| F6 | 宠物闹钟/提醒（一次性 cron + 宠物到期提醒） | 到期弹气泡 + 系统通知 + 动画 |
| F7 | 宠物拖拽记忆 + 多显示器跟随 | 重启保持位置；跨屏拖动正常 |
| F8 | 互动小游戏/彩蛋（摸摸→反应、双击→旋转） | 交互有反馈 |

## 4. 非功能

- 动画流畅 ≥30fps；宠物窗口常驻内存 < 60MB。
- 富文本渲染与主面板共用同一渲染器（抽共用模块）。
- 闹钟数据随迁移导出/导入。

## 5. 边界

- 不做 3D 宠物/骨骼动画（超范围）。
- 皮肤生成依赖现有 ImageGen 管道，离线走默认帧样式。

## 6. 验收清单

- [ ] F1–F8 全过；宠物动画/气泡/任务/闹钟均可用且测试覆盖
- [ ] 换形象后宠物皮肤即时更新
