# G6-SPEC — 打包·安全·分发

> Goal：G6 · 状态：🟡 进行中（2026-11） · 上游：[AUDIT.md](../AUDIT.md)（缺口 #7）· 下游：[G6-design](./G6-design.md)
> 目标：从「开发态可跑」到「可分发、可更新、密钥安全、行为可审计」的成熟 macOS 应用。

## 1. 问题陈述

当前只能 `bun run start` 开发态；无 dmg/签名/公证/自动更新；apiKey 明文落 `config.json`；无版本管理与升级路径。

## 2. 用户故事

- 作为用户，我拿到一个 **.dmg 安装包**，拖入 Applications 即用；首次启动无 Gatekeeper 拦截（已签名公证）。
- 作为用户，应用**自动检查更新**，一键重启升级，我的 bot/会话/记忆不丢。
- 作为用户，我的模型 key 保存在**系统钥匙串（Keychain）**，不落盘明文。
- 作为用户，我可以**导出审计日志**（授权/工具执行），知道 bot 做了什么。

## 3. 功能需求

| # | 需求 | 验收 |
|---|------|------|
| F1 | 打包产物（dmg + 通用/ARM 架构） | `bun run dist` 产出可安装 dmg |
| F2 | 代码签名 + 公证（Developer ID） | 非开发者模式跳过但记录；
真实签名时 Gatekeeper 通过 |
| F3 | 自动更新（electron-updater 或自建） | 检测→下载→重启升级，数据保留 |
| F4 | Keychain 密钥管理（读写/迁移） | key 不落明文文件 |
| F5 | 升级迁移（数据目录版本化 + v3 迁移） | 升级后 bot/会话/记忆完整 |
| F6 | 崩溃与日志（主进程/渲染器日志轮转） | 断点可查 |
| F7 | 审计导出（CSV/JSON） | 一键导出 | 
| F8 | 版本信息与更新渠道（stable/beta） | 面板显示版本/渠道 |

## 4. 非功能

- 安装包 < 120MB；启动 < 3s。
- 签名/公证仅在配置了证书时执行，无证书不阻塞开发构建。
- 数据目录 `~/.harness-bot/` 结构版本化（`schema_version`）。

## 5. 边界

- 不做应用商店上架（可后续）；不做企业分发服务。
- 自动更新默认 stable 渠道，beta 开关可选。

## 6. 验收清单

- [ ] F1–F8 全过；dmg 产物存在且可安装；key 走 Keychain；升级迁移往返通过
- [ ] 无证书时 `bun run dist` 仍产出未签名 dmg（标记 unsigned）
