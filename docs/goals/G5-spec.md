# G5-SPEC — 系统深度接入

> Goal：G5 · 状态：⏳ 待实现 · 上游：[AUDIT.md](../AUDIT.md)（缺口 #6）· 下游：[G5-design](./G5-design.md)
> 目标：让 bot 在**显式授权**下能真正操作本机（应用自动化、键鼠、屏幕、系统命令分组），每次操作留痕可审计。

## 1. 问题陈述

SystemKit 只有通知/剪贴板/文件白名单；无授权弹窗、无 AppleScript/键鼠/屏幕能力、bash 命令白名单过窄。bot「深入系统」只能看不能动。

## 2. 用户故事

- 作为用户，bot 想用系统能力（读屏幕/按键盘/操作应用）时，会**弹出授权请求**，我批准后才执行。
- 作为用户，我给 bot 授权「控制浏览器」「执行 git 命令」等**分组能力**，一次批准长期有效。
- 作为用户，我可以**查看审计日志**：谁在什么时间请求了什么系统能力、结果如何。
- 作为用户，bot 可以**打开/操作应用**（AppleScript：打开 Safari、发消息、截图），我可以一键撤销授权。

## 3. 功能需求

| # | 需求 | 验收 |
|---|------|------|
| F1 | 能力分组（notify/clipboard/fs/bash/gui/screen/apple） | 按组授权、按组拒绝 |
| F2 | 授权请求弹窗（bot→用户） | 未授权时 bot 调用被挂起，弹窗批准/拒绝/一次/长期 |
| F3 | AppleScript 执行（打开应用/控制 Safari/系统事件） | 授权后执行成功并回传结果 |
| F4 | 键鼠（typing/click/hotkey） | 授权后输入/点击生效（走 AppleScript `System Events`） |
| F5 | 屏幕截图（区域/全屏） | 授权后截图保存并可注入会话（image 块） |
| F6 | bash 命令白名单分组（read/dev/git/net/io） | git 状态/提交、网络、文件按组放行 |
| F7 | 审计日志（请求/授权/执行/结果/耗时） | 面板可查、导出 |
| F8 | 授权撤销/过期 | 一键撤销 + 定时过期 |
| F9 | 危险操作二次确认 | rm -rf 等触发强确认 |

## 4. 非功能

- 每次授权与执行都落审计；日志只增不删（可轮转）。
- GUI 自动化依赖 macOS 辅助功能权限（System Settings 引导检测）。
- 所有系统操作默认 deny；只有显式授权才 allow。

## 5. 边界

- 不做屏幕内容理解（AI 视觉理解由模型层负责，截图仅采集）。
- 不做远程控制/外网暴露。

## 6. 验收清单

- [ ] F1–F9 全过；授权弹窗/审计/撤销链路可用且有测试
- [ ] 真实 AppleScript（打开应用）冒烟通过
