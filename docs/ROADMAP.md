# ROADMAP — Harness Bot 多 Goal 路线图

> 日期：2026-10-27 · 流程：Audit → Goal(s) → Spec → Design → Task → 实现
> 上游：[AUDIT.md](./AUDIT.md) · MVP 已达成（GOAL.md G1–G9 ✅）

## Goal 总览

| Goal | 名称 | 一句话 | 依赖 | 验收锚点 |
|------|------|--------|------|----------|
| **G1** | 会话与上下文工程 | 会话可搜索/归档/分页，上下文按 token 预算自动裁剪，长对话不失控 | — | 10k 消息会话秒开；自动压缩生效 |
| **G2** | 记忆升级（向量+共享） | 语义检索 + MEMORY.md 权威总结常驻 + 跨 bot 共享知识 | G1（上下文治理） | 模糊问题召回正确记忆；跨 bot 共享生效 |
| **G3** | 桌面宠物深度化 | 多形态动画 + 气泡会话入口 + 定时任务结果进宠物 + 任务闹钟 | — | 宠物可看历史、定时任务完成在宠物气泡展示 |
| **G4** | 多 bot 协作与编排 | 群组广播 + 富内容互发 + 主控编排器（一个指令调动多 bot） | G1（消息体） | 编排一场「A 调研→B 总结→C 写作」流水线 |
| **G5** | 系统深度接入 | 授权确认弹窗 + AppleScript/键鼠/屏幕截图 + 命令白名单分组 | — | bot 经授权后能操作本机应用；每次授权留痕 |
| **G6** | 打包·安全·分发 | dmg 打包 + 签名公证 + 自动更新 + Keychain 密钥 + 审计日志 | 全部 | 可分发安装包；key 不落盘；升级静默 |

## 执行顺序与并行

```
G1 ──→ G2 ────────────┐
G3 ───────────────────┼──→ G6（打包前置：G3/G4/G5 功能稳定后）
G4 ──(依赖 G1 消息体)──┤
G5 ───────────────────┘
```

- G1/G3/G5 可并行起步（改动面不重叠）；G2 依赖 G1 的上下文治理；G4 依赖 G1 的富消息体。
- 每个 Goal 独立出 `docs/goals/G{n}-*.md` 三件套，完成即把 ROADMAP 对应行标 ✅。
